プライバシーポリシー

制定日：2026年10月29日

いわみマネークリニック株式会社（以下「当社」といいます）は、当社代表者が使用する内部業務用事務ツールにおけるGoogleユーザーデータの取り扱いについて、以下のとおり定めます。

本ツールは、一般顧客向けサービスではなく、当社代表者本人が自身のGoogleアカウントを利用して業務を行うための内部業務ツールです。

1. 取得する情報

本ツールでは、本人がGoogle OAuthにより許可した範囲で、以下の情報を取得する場合があります。

Gmailに関する情報

  • メールの件名
  • 差出人
  • 宛先
  • 送受信日時
  • メール本文
  • 添付ファイルの有無
  • 業務上必要なメール情報

Google上の本人管理データ

  • 本人が管理するスプレッドシート
  • 本人が管理するフォーム
  • その他、本人が明示的にアクセスを許可したGoogleデータ

取得する情報は、実際に本人がGoogle OAuth画面で許可した範囲に限定します。

2. 利用目的

取得したGoogleユーザーデータは、以下の本人の事務業務のために利用します。

  • 業務メールの内容確認
  • 講師派遣、食堂運営、発注、報告、その他の事務処理
  • 返信文、報告文等の下書き作成
  • Gmail上への下書き保存
  • 未処理案件の確認および本人への通知
  • スケジュールや会場情報の整理
  • 移動距離・経路確認
  • 本人の業務記録の整理
  • 本人が利用するPC、Notion等への必要事項の記録

3. Googleユーザーデータの第三者提供

取得したGoogleユーザーデータを、広告、販売、マーケティング、名簿作成その他これらに類する目的で第三者へ提供・販売することはありません。

また、Google APIから取得したユーザーデータを、AIまたは機械学習モデルの学習・改善目的には使用しません。

ただし、本人の業務を実行するために必要な場合に限り、必要最小限の情報を外部サービスへ送信する場合があります。

例として、移動距離や経路の計算を行う際に、必要な住所情報のみをGoogle Maps等の経路計算サービスへ送信する場合があります。

その際、業務上不要なメール本文全体を送信することはありません。

4. データの保存

Google OAuthによって発行されたアクセストークン、更新トークンその他の認証情報は、代表者本人が管理するPC等の環境に保存します。

業務上必要な件名、差出人、日付、会場、住所、対応状況等については、本人が管理するPC、Notionその他の業務管理環境へ保存する場合があります。

保存する情報は、本人の業務遂行に必要な範囲に限定します。

5. データの削除

本人は、Googleアカウントのセキュリティ設定から、本ツールによるGoogleアカウントへのアクセス権をいつでも解除できます。

アクセス権を解除すると、それ以降、本ツールはGoogleアカウントから新たなデータを取得できなくなります。

保存済みの業務記録等の削除を希望する場合は、以下の連絡先までご連絡ください。

info@imc-fp.com

6. Google API Services User Data Policy

本ツールによるGoogle APIから取得した情報の使用および他のアプリへの転送は、Google API Services User Data Policyに従い、Limited Use requirementsを含む各要件に準拠して行います。

7. 安全管理

取得したGoogleユーザーデータについて、本人以外が不必要にアクセスできないよう、適切な管理を行います。

認証情報やGoogleユーザーデータを、公開された場所へ保存することはありません。

8. プライバシーポリシーの変更

本ポリシーは、Google APIの利用方法、業務内容または関連法令・規約等の変更に応じて改定する場合があります。

重要な変更がある場合には、本ページ上で内容を更新します。
